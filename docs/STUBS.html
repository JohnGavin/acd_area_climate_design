Real WFS Schemas (verified 2026-05-01 via DescribeFeatureType)

ogdwien:ENERGIERAUMPLANOGD (zones)

OBJECTID, ID, ERPLABEL, BEZNR (district number), GEBID (building ID — pre-linked!), FL_ERP (zone area), PLANNR, VERSION, BEARB_DATUM (date last edited), WEBLINK_PD, WEBLINK_VO (legal document URL), SHAPE.

No native ERPTYP or ERPRECHTSTAT — zone type / legal status must be inferred from ERPLABEL parsing or by following WEBLINK_VO.

ogdwien:GEBAEUDEINFOOGD (buildings)

OBJECTID, IDENT_1/2/3 (composite ID), ACD (already populated — possibly THE answer column), BAUJAHR (year built), BEZ (district), BEZNR is missing — district name in BEZ, GESCH_ANZ (number of stories), STRNAML+VONA+VONN / BISA+BISN (street + number range = address), STRCD (street code), HA_NAME (Hauptanschrift name), L_BAUJ / L_BAUTYP / L_NUTZUNG (use codes), ARCHITEKT, BASIS_INV, CONSCR_NR, ORIG_DACH/FASS/FENSTER/KERN/PARZ (originality flags), PR_MA19, STGA/STGN, NS, SHAPE.

No HOEHE (height) field — was assumed, not present. Using GESCH_ANZ (story count) as height proxy.

acd_agreement factor “spatial=acd_native” / “mismatch” / “spatial_only” / “acd_only” / “neither” NEW: cross-validation of pre-linked ACD vs spatial join

link_status enum (drives the dashboard tabsets)

value meaning dashboard tab
in_zone building entirely within one zone “Clean join”
outside_any_zone centroid outside all zones — legitimate, not error “Outside any zone”
straddles_boundary overlap fraction in (0.05, 0.95) “Straddles boundary”
multiple_zones n_overlapping_zones > 1 “Multiple zones”
orphan_zone (zones-side) zone with 0 buildings “Orphan zones”
invalid_geometry st_is_valid == FALSE “Invalid geometry”

Conventions

  • Use gert for git operations from R, gh CLI from bash
  • Use git -C <path> — NEVER cd <path> && git ... (see global rule git-no-compound-cd)
  • Run R via nix-shell <path>/default.nix --run "Rscript -e ..." (project-specific shell)
  • All prose values in vignette use embedded r expr (rule dynamic-prose-values)
  • Apply analysis-rationale-logging for any analytical choice
