# acd: Vienna Area Climate Design building-zone linkage

Proof-of-concept R package linking Vienna's Energieraumpläne (ACD zones) to the building inventory (Gebäudeinformation) via spatial join.

Snapshot date: 2026-05-01. Sources: data.wien.gv.at WFS.
